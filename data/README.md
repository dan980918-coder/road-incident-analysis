# 데이터 안내

## 출처

ITS 국가교통정보센터(https://www.its.go.kr)에서 제공하는 도로 돌발상황(돌발정보) 데이터를
전처리한 파일입니다.

## 파일

| 파일 | 설명 | 용량 | 저장소 포함 여부 |
|---|---|---|---|
| `incident_data.csv` | 원본 전처리 완료 데이터 (약 62.3만 행) | 140MB | ❌ (`.gitignore`, GitHub 100MB 제한 초과) |
| `incident_data_sample.csv` | 위 데이터에서 무작위 2,000행 추출 (시간순 정렬) | 약 440KB | ✅ |

전체 데이터로 노트북을 재현하려면 ITS 국가교통정보센터에서 동일한 기간의 돌발정보를
내려받아 아래 스키마에 맞게 전처리한 뒤 `incident_data.csv`로 이 폴더에 넣으면 된다.

## 스키마 (15개 컬럼)

| 컬럼 | 설명 | 예시 |
|---|---|---|
| `돌발일시` | 돌발상황 발생 일시 | `2025-10-31 23:59` |
| `관리기관` | 도로 관리 기관 | `한국도로공사` |
| `도로타입` | 도로 종류 | `고속국도`, `일반국도`, `도시고속도로`, `특별광역시도`, `시군도`, `지방도`, `국가지원지방도` |
| `도로번호` | 노선 번호 | `55` |
| `도로명` | 노선명 | `중앙고속도로` |
| `방향` | 진행 방향 | `부산 방향` |
| `돌발구분` | 대분류 | `기상`, `공사`, `교통사고`, `재난`, `기타돌발`, `기타` |
| `돌발상세구분` | 소분류 | `강우`, `작업`, `사고`, `고장`, `차량증가/정체` 등 |
| `돌발내용` | 자유 텍스트 상세 내용 (위치·차로 정보 포함) | `<사고>::경부고속도로::...::1차로::고장 ...` |
| `X` | 경도 | `127.9197` |
| `Y` | 위도 | `37.3340` |
| `링크아이디` | 도로망 링크 ID | `2510032001` |
| `돌발종료일시` | 종료 일시 (미기재 시 `-`) | `-` |
| `요일` | 요일 (영문) | `Friday` |
| `요일구분` | 평일/주말 구분 | `평일` |

데이터 기간: 2024-11-06 ~ 2025-10-31.
