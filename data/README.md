# 데이터 안내

## 출처

ITS 국가교통정보센터(https://www.its.go.kr)에서 제공하는 도로 돌발상황(돌발정보) 데이터를
전처리한 파일입니다.

## 파일

| 파일 | 설명 | 용량 | 저장소 포함 여부 |
|---|---|---|---|
| `incident_data.csv` | 원본 전처리 완료 데이터 (약 62.3만 행) | 140MB | ❌ (`.gitignore`, GitHub 100MB 제한 초과) |
| `incident_data.csv.gz` | 위 파일을 gzip -9로 압축한 버전 | 약 21.5MB | ✅ |
| `incident_data_sample.csv` | 위 데이터에서 무작위 2,000행 추출 (시간순 정렬) | 약 440KB | ✅ |

저장소에 압축된 전체 데이터(`incident_data.csv.gz`)가 포함되어 있어 별도 다운로드 없이
클론만 하면 바로 노트북을 실행할 수 있다. `src/load_data.py`의 `load()`가
`pandas.read_csv`로 `.gz` 확장자를 자동 인식해 압축을 풀어 읽는다.

## 스키마 (15개 컬럼)

| 컬럼 | 설명 | 예시 |
|---|---|---|
| `돌발일시` | 돌발상황 발생 일시 | `2025-10-31 23:59` |
| `관리기관` | 도로 관리 기관 | `한국도로공사` |
| `도로타입` | 도로 종류 | `고속국도`, `일반국도`, `도시고속국도`, `특별광역시도`, `시군도`, `지방도`, `국가지원지방도` |
| `도로번호` | 노선 번호 | `55` |
| `도로명` | 노선명 | `중앙고속도로` |
| `방향` | 진행 방향 | `부산 방향` |
| `돌발구분` | 대분류 | `기상`, `공사`, `교통사고`, `재난`, `기타돌발`, `기타` |
| `돌발상세구분` | 소분류 | `강우`, `작업`, `사고`, `고장`, `차량증가/정체` 등 |
| `돌발내용` | 자유 텍스트 상세 내용 (위치·차로 정보 포함) | `<사고>::경부고속도로::...::1차로::고장 ...` |
| `X` | 경도 | `127.9197` |
| `Y` | 위도 | `37.3340` |
| `링크아이디` | 도로망 링크 ID | `2510032001` |
| `돌발종료일시` | 종료 일시 (미기재 시 `-`) | `-` |
| `요일` | 요일 (영문) | `Friday` |
| `요일구분` | 평일/주말/공휴일 구분 | `평일` |

데이터 기간: 2024-11-01 ~ 2025-10-31 (API 수집 기준). ITS API로 수집한 원본은
636,320건이며, 여러 전처리 단계(수집 기간 밖 `돌발일시` 326건 제거, 도로명/도로번호
결측 보완, `돌발상세구분` 결측 채움, `돌발내용`이 없는 행 제거 등)를 거쳐 최종
`incident_data.csv`는 623,188건이다(정제된 데이터의 실제 최초 기록은 2024-11-06).

## 행정경계 데이터 (`boundaries/`)

`src/region_mapping.py`가 위경도를 시/도로 분류할 때 사용하는 참고 데이터입니다.

- 출처: 통계청 SGIS(https://sgis.kostat.go.kr) 2018년 시/도 경계, 공공누리 제1유형
  라이선스로 배포되는 [southkorea/southkorea-maps](https://github.com/southkorea/southkorea-maps)
  리포지토리의 GeoJSON을 사용
- `skorea_provinces_simplified.geojson`: 저장소 용량을 위해 형상을 단순화
  (simplify tolerance 0.0005도)한 버전. 원본 대비 전체 62.3만 건 중 172건(0.03%)만
  다르게 분류된다.
